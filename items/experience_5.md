# Building My Own Roblox Game

## What was it that I did?

I've been making my own game in Roblox Studio. Most of it has been learning how to script and figuring out how all the pieces of a game fit together. Next I want to start using Blender so the models look better.

## When did I do it?

I started this fall and I'm still working on it.

## What was good about it?

It's cool to come up with an idea and then actually see it work. It also lines up with what I'm learning in UX, because I have to think about how players move through the game and what would make it easy or annoying to play.

## What was my favourite memory of it?

The first time I playtested it and something I built worked exactly how I imagined it.

## What didn't I enjoy about it?

Debugging. One small thing breaks and I can spend forever trying to figure out why. Learning Blender on top of Studio is a lot too.

## Grade: B

I enjoy it most of the time. It gets frustrating, but it's worth it when things finally work.
